## Entry Points for Contributors

**Start anywhere. Fork freely. No permission needed.**

### Story Entry Points

- Write a scene where a character discovers an everyday object (a spoon, a book, a coat) behaving according to its original, pre-colonial purpose or material truth, not its current use.
- Create a dialogue between a surrealist painter and an Indigenous elder describing the same 'broken' phenomenon, one in artistic terms, the other in spiritual/cosmological terms.
- Draft a 'legal document' from the perspective of the land itself, listing grievances and terms for a new treaty with humanity.
- Imagine a 'Council of Broken Things'—a gathering of inanimate objects and natural features that have begun to malfunction. What do they debate? What is their plan?

### Technical Entry Points

- Build an interactive web experience where text flows in multiple directions (like the river), and the user must 'listen to the between sound' to navigate and reveal the story.
- Create a generative art piece that uses a map as a seed. The program 'unpicks' the map based on user interaction, slowly transforming it from political boundaries into ecological or ancestral memory patterns.
